# Background folders

`context-db/<name>-project/` is the project folder. Every other folder at the
top level of `context-db/` is a background folder: standards or reference
knowledge that is not specific to this project and usually lives in another
repository. Each one is an OKF bundle in its own right.

## Rules

- Mount only at the top level of `context-db/`.
- Commands never write to a background folder.
- A folder meant for sharing links only within itself.
- Its `index.md` files are generated in the repository that owns it:
  `context-db.py index context-db/<folder>`.

Reasons are in
[links-and-symlinks.md](./design-decisions/links-and-symlinks.md) and
[static-index.md](./design-decisions/static-index.md).

## Ways to mount

| Method               | Who sees it  | In git                        | Updates                |
| -------------------- | ------------ | ----------------------------- | ---------------------- |
| Committed copy       | Everyone     | Yes                           | Re-copy                |
| Symlink + .gitignore | Only you     | No                            | Follows the other repo |
| Submodule + symlink  | Everyone     | Yes, pinned                   | `git submodule update` |
| git-sync + symlink   | Configurable | Shared config yes, private no | `git-sync sync`        |

A private mount works because the list of folders is generated on every
`/context-db prompt`: your agent sees the symlink, a teammate's does not, and
nothing committed changes.

The symlink may use a different name than the source folder. The descriptor is
looked up under the real folder name first.

[git-sync](https://github.com/cart0113/GIT_GIT_SYNC) supports sparse checkout of
just a repo's `context-db/` and separate committed and private configs.

## This repository's own mounts

`.gitignore` lists several `context-db/<name>` entries. They are the owner's
private mounts and exist only on their machine. `context-db/writing-effective-skills`
is a committed symlink into a sibling repository, so it is broken in any clone
that lacks that sibling; `prompt` reports it and moves on.
