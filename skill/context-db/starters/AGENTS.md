# context-db

This project keeps its knowledge base in `context-db/`: a hierarchical Markdown
wiki of conventions, decisions, gotchas, and current plans, in Open Knowledge
Format.

**Do not read, load, or browse `context-db/` on your own.** It is not background
reading; pulling it into context unprompted wastes tokens and degrades your
answers. Engage with it only when the user invokes a `/context-db` command
(`prompt`, `update`, `wip`, `configure`). The command prints exactly what to do.
