# How to Navigate context-db

To list a folder, run:

    {toc_cmd} <folder>

It prints each file and subfolder with its description, built from the files
as they are now, so it is never out of date. Use it every time you look into
a folder, now or later in the session, instead of listing the folder, opening
files to see what they are, or reading an `index.md` that the folder may
carry.

- Open a file, or list a subfolder, only when its description bears directly
  on the task. Skip everything else.
- Links inside a file are relative to that file.
